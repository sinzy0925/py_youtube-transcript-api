1. 一言サマリー
誰向け・テーマ: オルカン（全世界株式ファンド）を活用して資産1億円を目指す投資家向けに、過去38年間のデータを用いた一括投資・積立投資・併用型の検証結果とロードマップを解説する動画。
動画の構成: オルカンの仕組みと前提データの解説、1,392ケースの検証結果（一括・積立・併用）、期間ごとの資産推移と暴落への備え（ドローダウン）、まとめと代替提案。

2. 対象者・前提条件
対象者: オルカンで1000万円、3000万円、5000万円、最終的に1億円の資産形成を目指す人。
前提条件: 
- 投資対象は全世界株式ファンド（MSCIオールカントリーワールドインデックス / ACWI）。
- 使用データは1987年12月から2026年7月までの38年7ヶ月の月次データ。
- 元データは米ドル建て（為替影響、信託報酬、税金は除外）。ACWIの公表開始は2001年のため、それ以前は当時のルールに基づくバックテスト。
- 検証パターンは合計1,392ケース（464通り×3手法）。

3. 制度・商品・施策名と要点
オルカン（ACWI / MSCIオールカントリーワールドインデックス）の要点:
- 先進国23カ国、新興国24カ国を含む、2026年7月末時点で2,460銘柄で構成（投資可能市場の約85%をカバー）。
- 企業の時価総額に応じて配分が決定されるため、国別では米国が約63%、日本が約5.1%。
- セクター別では情報技術テクノロジーが約30%。上位10銘柄だけで24%を占める（NVIDIA、Apple、Microsoftなど）。
- 2026年8月13日に組入れ銘柄の変更が発表され、国際エレクトリックが追加、JFEセーブホールディングス（動画内表記）が除外。

投資手法の検証結果と特徴:
- ルートA（一括投資）: 最初に1000万円を一括投資し、以降追加投資しない方法。早い段階から大きな元本を市場で働かせるメリットがあるが、開始時期によって最大約9年の差が出る。
- ルートB（積立投資）: 最初から毎月10万円を積み立てる方法。高値も安値も関係なく淡々と口数を買い続けられる。資産が育つにつれて運用益の影響が大きくなる。
- ルートC（併用型）: 最初に1000万円を投資し、翌月から毎月10万円を追加する手法。元本が大きく、継続資金も入るため最も早く1億円に到達する。

4. 数字一覧
- 構成比率（ACWI）: 米国約63%、日本約5.1%、情報技術約30%、上位10銘柄で24%。
- オルカンの複利リターン（過去データ）: 年率リターン約8.9%。
- 月次リターンの振れ幅: 最も高かった月が2020年11月の+12.4%、最も下がった月が2008年10月の-19.8%。
- ルートA（1000万円一括）の到達期間: 最速22年11ヶ月（2003年3月開始）、中央値29年8ヶ月、最も遅いケース31年10ヶ月。30年間追跡した104ケース中65ケースが1億円到達、35年間追跡した44ケースは全件到達。
- ルートB（毎月10万円積立）の到達期間: 最速22年3ヶ月（2004年2月開始）、中央値26年1ヶ月（元本3140万円）、最も遅いケース28年7ヶ月（元本3440万円）。
- ルートC（併用型: 1000万円一括＋毎月10万円積立）の到達期間: 最速14年8ヶ月（2011年9月開始）、中央値18年11ヶ月（元本3270万円）、最も遅いケース22年5ヶ月。20年以内の到達は46.9%、25年追跡の164ケースは全件到達。
- 暴落時の下落率（ドローダウン）: 最大下落率は2009年2月（リーマンショック時）の-54.6%。

5. メリット / デメリット / リスク
メリット:
- オルカンは世界の主役の入れ替わりに合わせて指数の中身が自動で変わるため、勝ち組の国を自分で当て続ける必要がない。
- 積立や併用型では、暴落時に同じ金額で多くの口数を購入できる。
デメリット・リスク:
- 開始する時期（相場の巡り合わせ）によって、1億円到達までに約9年の差が生じる。
- 1億円到達後にリーマンショック級の最大-54.6%の暴落が来ると、評価額が半減するなどの大きな精神的衝撃を受ける。
- オルカン単体では資産を増やすのに時間がかかる場合がある（動画内ではナスタ100等のハイリスク・ハイリターンファンドを混ぜる選択肢も言及）。

6. 視聴者が取れるアクション
- 自分の入金額を確認し、月いくら投資に回せるかを把握する。
- 投資の初期段階（資産が少ない時期）は、商品の利回りよりも「積み立てをやめないこと」と「入金額を育てること」を優先する。
- 積立設定を自動化し、固定費を削減できた年だけ増額する仕組みを作る。
- 生活費を別に確保し、近く使うお金は株に入れない設計にする。
- 暴落時に途中で売却（退場）しないための心構えと準備を行う。
