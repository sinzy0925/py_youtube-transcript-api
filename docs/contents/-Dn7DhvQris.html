1. 一言サマリー
動画内では、2027年の制度変更を見据えたiDeCo（個人型確定拠出年金）と新NISAの比較・活用戦略について解説されている。対象者は40代・50代・60代の会社員など。動画の構成は、2027年の制度変更点の説明、全20ケースのシミュレーション、上限額（6万2000円）全額投入時の比較、5ステップの計算方法、年代・年収別の判断表、および退職金・既存DC残高がある場合の逆転ラインの解説となっている。

2. 対象者・前提条件
対象者：40代、50代、60代の会社員など。
シミュレーションの前提条件：
- 2027年1月から65歳まで積み立て（利回り年5%の想定）。
- iDeCoと新NISAで同じ低コスト投資信託を購入。
- iDeCoは65歳で一時金受取を前提。
- 会社の退職金なし、現在のiDeCo・企業型DC残高は0（一部章で例外あり）。
- 所得控除で減った税金は運用せず現金で保有（新NISAで再投資しない）。
- iDeCo固有の口座手数料（年間約2000円）は除外。
- iDeCoは60歳まで引き出せない制約を理解の上で投資。
- 企業年金のない会社員の標準的な年収モデル（年収300万円〜1100万円）の税率を使用。

3. 制度・商品・施策名と要点
2027年のiDeCo制度変更点（動画内の説明）：
- 企業年金のない会社員：毎月の上限が2万3000円から6万2000円に増加。
- 自営業者など（国民年金基金などと合わせた上限）：6万8000円から7万5000円に増加。
- 加入可能年齢：65歳未満から70歳未満に変更。

iDeCoと新NISAの比較・判断の要点：
- 50代は所得控除を10〜15年受けられ、運用期間が30年ほど長くないため、残高が退職所得控除を大幅に超えにくく、iDeCoと相性が良い年代であると説明されている。
- 40代は所得控除期間が長い一方、運用期間も長いため総額が増え、出口での課税を免れないケースがある。また教育費や住宅費が残る場合、10年以内に使う予定のお金を除いて老後専用資金として投入すべきとされる。
- 運用利回りが上がるほど出口の税金が増えるため、新NISAとの差が小さくなる。

自ら計算する5ステップ（動画内手順）：
- ステップ1：自分の税率を確認する（源泉徴収票の「給与所得控除後の金額」から所得控除の合計額を引いて課税所得を出し、税率を確認）。
- ステップ2：65歳時点の残高を算出する。
- ステップ3：積み立て中に減る税金を計算する（年間掛け金×合計税率×積み立て年数）。
- ステップ4：出口の税金を計算する（退職所得控除を計算し、iDeCo残高から控除額を引いて1/2にして課税退職所得を出し、所得税・復興特別所得税・住民税を算定）。
- ステップ5：入り口（減った税金）と出口（増える税金）を引き算し、有利額を判定する。

退職金・既存DCがある場合の考慮点：
- 会社の退職金、現在のiDeCo・企業型DCの65歳時点予想残高、これから増額する掛け金の3つを確認する。
- 同じ年に複数の退職所得等を受け取る場合、原則として合算して勤続年数の重複も調整して退職所得控除を計算する。
- 受け取りの年を1年以上ずらすと重複期間の調整は入るが原則最低80万円の退職所得控除が使える場合がある（ただし必ず得とは限らないため、同一年受取とずらす場合の両方を計算して決める）。

4. 数字一覧
- 2027年以降の掛け金上限（企業年金なし会社員）：月2万3000円 → 月6万2000円
- 国民年金基金等との合算上限（自営業者など）：月6万8000円 → 月7万5000円
- 加入可能年齢：65歳未満 → 70歳未満
- シミュレーション前提の利回り：年5%（一部3%、7%の比較あり）
- iDeCo口座手数料：年間約2000円（シミュレーションでは除外）
- 50歳・年収500万円（月5万円拠出、年5%）の例：
  - 月1万円拠出：元本180万円、65歳時267万円、税金0円、新NISAより36万円お得
  - 月3万円拠出：元本540万円、65歳時802万円、積立中減税109万円、出口課税15万円、新NISAより94万円お得
  - 月5万円拠出：元本900万円、65歳時1336万円、積立中減税182万円、出口課税68万円、新NISAより114万円お得
  - 月6万2000円拠出：元本1116万円、65歳時1657万円、積立中減税226万円、出口課税117万円、新NISAより108万円お得
- 利回り別の比較（50歳・年収500万円・月5万円）：
  - 年利3%：65歳時約1135万円、出口課税約44万円、新NISAより約90万円有利
  - 年利5%：65歳時1336万円、出口課税68万円、新NISAより114万円有利
  - 年利7%：65歳時1585万円、出口課税106万円、新NISAより76万円有利
- 退職金＋既存DCの逆転ライン（55歳から月5万円・年5%運用前提）：
  - 年収300万円：約260万円
  - 年収500万円：約3230万円
  - 年収700万円：約5590万円
  - 年収1100万円：約9770万円
- 退職所得控除の計算基礎（動画内例）：勤続20年以下は1年につき40万円、20年超は1年につき70万円。

5. メリット / デメリット / リスク
メリット：
- 拠出時に所得控除が受けられるため、所得税・住民税が軽減される。
- 50代は所得控除期間を10〜15年確保でき、運用期間が長すぎないため出口課税が膨らみにくい。
デメリット・リスク：
- 60歳まで原則として引き出せない制約がある。
- 運用益や積立額が大きい場合、出口（受給時）に課税される退職金・一時金の税金が増える可能性がある。
- 企業型DCや既存の退職金が大きい場合、新NISAの方が有利になるケースがある。

6. 視聴者が取れるアクション
- ステップ1：自身の年齢と年収を確認し、年代・年収別の判断表または5ステップで自分の場合を計算する。
- ステップ2：10年以内に使う予定のお金を除外し、老後専用資金を見極める。
- ステップ3：退職金や既存DC残高がある場合は、65歳時点の予想残高と退職金の合計額を確認し、逆転ライン（例：55歳・年収500万円の場合は約3230万円）と比較する。
- ステップ4：受取時期を退職金と合わせるか、1年以上ずらすかを出口の税額を踏まえて検討する。
- ステップ5：条件に応じて、iDeCoへの拠出（上限枠または月5万円など）と新NISAの併用配分を決定し実行する。
