1. 一言サマリー（誰向け・テーマ）
40代から60代の会社員を対象に、2027年の制度改正に伴うiDeCo（個人型確定拠出年金）の上限拡大やNISAとの比較、年代・年収別のシミュレーションを解説した金融・制度解説動画。

2. 対象者・前提条件（年齢、所得、世帯、雇用形態 等）
- 対象者: 40代、50代、60代の会社員（企業年金のない会社員等）
- 所得の前提: 年収300万円から1100万円程度
- 雇用形態: 主に会社員（動画内の標準的モデルに基づく）
- 前提条件: 運用期間、退職金・既存DC残高の有無、65歳受給開始などを仮定してシミュレーションを実施

3. 制度・商品・施策名と要点
- 制度名: iDeCo（個人型確定拠出年金）、新NISA
- 要点: 2027年の法改正により、企業年金のない会社員等の拠出限度額が引き上げられる予定（動画内説明）。所得控除による節税メリットと、受取時の出口課税（退職所得控除等）のバランスを考慮してNISAと比較・併用することが推奨されている。

4. 数字一覧（金額・率・上限・期限）※文字起こしにあるもののみ。無い数字は捏造しない
- 2027年以降の上限額（動画内説明）:
  - 企業年金のない会社員: 月額2万3000円から6万2000円に増加
  - 自営業者等（国民年金基金などと合わせる場合）: 月額6万8000円から7万5000円に増加
  - 加入可能年齢: 65歳未満から70歳未満に変更
- シミュレーションの仮定値: 想定年利回り5%（一部3%、7%の比較あり）、65歳時点での受給を前提
- 退職金・既存DCの逆転ライン（55歳・年収500万円のモデルケース）: 約3230万円

5. メリット / デメリット / リスク
- メリット: 毎月の掛金が所得控除の対象となり、積立期間中の所得税・住民税が軽減される。50代など期間が比較的短い場合でも、退職所得控除の枠内に収まりやすく相性が良いケースがある。
- デメリット / リスク: 原則として60歳まで資金を引き出すことができない。運用益や掛金の状況、退職金との合算によっては、受取時の出口課税（税金）が膨らみ、NISAとの有利性が逆転・縮小する場合がある。

6. 視聴者が取れるアクション（手順・時期）
- ステップ1: 源泉徴収票等を確認し、自身の課税所得と概算の税率を把握する。
- ステップ2: 自身の年齢・年収・運用利回りを仮定して65歳時点の残高を算出する。
- ステップ3: 積立期間中に軽減される税金額を計算する。
- ステップ4: 退職所得控除等を考慮して出口の税金額を計算する。
- ステップ5: 入口の節税額と出口の税金額を比較し、NISAとの併用や優先順位を判断する。
- 時期: 2027年の制度改正に向け、自身の年齢や年収に応じたシミュレーションを早期に行う。

7. 注意・免責（個別事情で変わる点、動画主張≠公式見解）
- 補助金・非課税・住民税に関する注意: 住民税非課税基準や税制優遇の適用は市区町村や年度、個人の所得構成によって異なるため注意が必要。
- 動画内の数値やシミュレーションはあくまで特定条件に基づく参考値であり、個別の適用結果を保証するものではない。動画の主張や試算結果は公式見解とは異なる場合がある。
