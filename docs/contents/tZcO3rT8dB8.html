負け癖を克服するための5つの鉄則（および関連手法）:
1. 良い損切りを学ぶ（利出しは遅くせず、悪材料が出た銘柄は売り、好材料が出た銘柄は買う）。
含み損が20%以上ある銘柄や、持って辛いと感じる銘柄は悪い銘柄である可能性が高いため一旦売却を検討する。
2. ポートフォリオの見直しは6ヶ月に1回程度で十分（頻繁なチェックは短期の値動きに惑わされ逆効果）。持ち株すべての成績表を確認し、指数に負けた銘柄の対応を考える。
3. 自分で決める（企業のIRページ等で事業内容や決算説明書を自分で読み、誰かの推奨銘柄をそのまま買わない）。
4. 売買する前に株価チャートを見る（テクニカル分析も重視）。
5. 成長株が現在どのステージにいるかを見極める。

小型成長株の3つのステージ:
- 黎明期: 利益がほとんど出ていないか赤字。将来の夢があり、PER50倍以上（赤字の場合は計算不可）。このステージで没落せずに成長することが重要。
- 急成長期: 売上高や利益が年50〜100%程度で伸びる。PERは30〜50倍程度。株式投資で一番旨味がある時期。
- 成熟期: 増益率が年率10%程度以下に落ち着き、PERは15〜20倍程度に低下。業績は良くても株価の伸びは鈍化する。

成長株を見極める4つの条件（NVIDIAの事例を活用したチェックポイント）:
1. 市場の成長性（市場のパイが今後どれくらい大きくなるか。例: NVIDIAの場合、生成AIを動かすGPU市場の急拡大）
2. 市場のシェア（その中でどれくらいシェアを取れているか。例: NVIDIAは生成AI用GPUで世界シェア9割超から7〜8割、最先端では独占的）
3. 参入障壁（参入するための壁の高さ。例: NVIDIAは技術的難易度が極めて高く最先端で独走）
4. マネタイズ力（上手に稼げるか。例: NVIDIAは高成長市場で圧倒的シェアを握り高い利益率を達成）
※不確実性がある段階で少し買って試行錯誤し、期待通りに進めば買い増し、ストーリーが崩れたら損切りする手法が紹介されている。

今後有望と考えられる4大成長テーマ:
- AI関連: インフラを作る企業（データセンター、AI半導体、クラウドサービス、サイバーセキュリティ、電力通信ネットワーク）と、活用して新しいサービスを生み出す企業（AIエージェント、フィジカルAI・ロボット、スマート建設業・農業、自動運転、コンテンツ、無型資産など。日本企業はコンテンツ産業や人材不足を補う建設・農業等に注目）。
- エネルギー革命: 電力需要の急増と脱炭素に対応する次世代エネルギー。地熱発電（地下20〜30kmの高温岩体地熱発電は商業利用段階手前）と核融合発電（日本は世界トップクラスの技術を持つがハードルが高い）。
- バイオ: 癌治療、ウイルス性疾患、遺伝子治療、予防医療、次世代食料品など（欧米に遅れを取る段階）。
- 宇宙開発: ロケット、人工衛星、次世代通信、GPS、防衛産業、宇宙基地など（欧米を追いかける段階）。

デメリット・リスク・罠:
- プロスペクト理論と同様の心理バイアス（利益が出ている銘柄を早く売り、含み損の銘柄をズルズル持ち続ける「悪い損切り」）に陥るリスクがある。
- 成長テーマ（AI、エネルギー等）として盛り上がっていることと、個別企業が本物の成長株であることは別問題であり、テーマ買いだけでは失敗するリスクがある。
- 黎明期の銘柄はPERが50〜100倍と高く、成長ストーリーが崩れて没落するリスクや、エネルギー（地熱・核融合）やバイオ・宇宙開発のようにテーマの投資タイミングが早すぎるリスクがある。

  1. 視聴者が取れるアクション
  2. 保有銘柄の成績表の確認: 6ヶ月に1度、保有銘柄の成績を確認し、指数に負けた銘柄や20%以上の含み損がある銘柄、持っていて辛い銘柄の売却（良い損切り）を検討する。
  3. 自分で企業情報を調査する: 他人の推奨銘柄をそのまま買わず、企業のIRページにアクセスし、事業内容や決算説明書を自分で読んでどの事業でどれくらい稼いでいるか確認する。
  4. 成長株の4つの条件によるスクリーニング: 投資検討銘柄について「市場の成長性」「市場のシェア」「参入障壁」「マネタイズ力」の4つの条件を満たしているかチェックする。
  5. ステージの把握と打診買い: 銘柄が黎明期・急成長期・成熟期のどのステージにあるかを確認し、不確実性がある段階ではまず少し買って試行錯誤し、期待通りに進めば買い増し、ストーリーが崩れたら損切りする。

  6. 割安セクターの活用: 成長株への偏重を避け、インフレに強い金融・資源関連・製造業の割安株への分散を検討する。
