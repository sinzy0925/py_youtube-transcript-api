1. 一言サマリー
誰向け: 資産1000万円を達成し、3000万円を目指している投資家向け。
テーマ: 1000万円から3000万円へ資産を増やすために本当に重要な5つのこと。
動画の構成: 資産1000万円到達後の特性の変化と、相場に長く残り続け確実に資産を拡大するための5つのポイント（複利の活用、下落時の継続、ルール化、生存率重視の設計、仲間・環境の重要性）についての解説。

2. 対象者・前提条件
・すでに資産1000万円を達成しており、さらに3000万円を目指している人。
・インデックス投資などを中心に長期的な資産形成を行っている人。

・新NISA制度: 2024年に開始された制度。動画内では金融庁速報値として、2025年12月末時点でNISA口座数が2826万口座、累計買付額が71兆円に増えていると言及。
・オルカン（全世界株式）・S&P500: コア資産として長期保有する手法の対象として挙げられている。
・ナスダック100、ファングプラス、半導体、ゴールド、インド、宇宙関連株: サテライト枠やハイリスクファンドとして、成長期待分野に組み込む選択肢として言及。
・バンガードのデータ（コロナショック時）: 2020年のコロナショック時に約95%の確定拠出年金の運用者が投資方針を維持したという調査結果を引き合いに、自動積み立てなど最初から仕組みを作っていた人ほど相場に反応しにくかったと説明。
・優投資ラウンジ: 運営者（ゆと）が主催する、長期的な行動を支え合う投資家向け会員制コミュニティ。

4. 数字一覧
・資産額の閾値: 1000万円、1500万円、2000万円、3000万円、5000万円。
・運用リターン・期間の試算（動画内の計算例）:
  - 1000万円を平均年率7%で運用し追加投資なしの場合、3000万円になるまで約16年。

  - 毎月10万円積み立ての場合、約8年1ヶ月。

5. メリット / デメリット / リスク
・メリット: 
  - 1000万円を超えると複利の効果と自身の資産による働き（相場の値動きによる増加）が大きくなり、入金額と同等かそれ以上に資産が増えるようになる。
  - 仕組み化（自動積み立てなど）を行うことで、暴落時にも相場に感情的に反応しにくくなり、投資を継続しやすくなる。
・デメリット / リスク:
  - 資産が増えるにつれて、リターンの高い商品への乗り換えや個別株（ナスダック100、半導体、ゴールド、高配当など）への浮気、暴落時の狼狽売りなど、余計な行動をとるリスクが増大する。
  - 暴落時に「自分が20%の暴落なら耐えられる」と額面だけで考えていると、3000万円が2400万円になるなど半年や1年働いても取り戻せない金額が数週間で消えた際に耐えられなくなるリスクがある。
  - 暴落時に手元に現金がない場合、車の故障や家の修繕、仕事の辞職などの急な出費に対応できず、最悪のタイミング（相場が30%下がっている時など）で株を売却せざるを得なくなるリスクがある。
  - 爆撃報告や資産額を競い合うSNS・コミュニティ環境に身を置くとう自身の投資方針が崩れたり遅れていると感じてしまうリスクがある。

・ステップ1: 資産1000万円到達時点で、自分にはすでに大きな複利のエンジンがあることを認識する。
