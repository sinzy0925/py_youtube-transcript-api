1. 一言サマリー（誰向け・テーマ）
資産形成を段階別に整理し、自分の資産レベル（レベル1〜3）に応じた最適な戦い方と投資の進め方を解説する内容（対象：資産形成の初心者から中級者）。

2. 対象者・前提条件
純資産額や生活の安定度によって異なる。
・レベル1：純資産160万円未満（1万ドル未満）、収支や急な出費に敏感な段階。
・レベル2：純資産160万円〜1600万円（1万〜10万ドル）、日常の買い物への不安は減るが暴落や大きな出費には弱い段階。
・レベル3：純資産1600万円〜1億6000万円（10万〜100万ドル）、投資の力が本格的に機能し始める段階。

3. 制度・商品・施策名と要点
・NISA（動画内説明）：積み立て投資の仕組みを活用した資産形成手法。
・インデックスファンド（オルカン、S&P500など）：低コストで広く分散された投資信託。
・コア・サテライト運用（動画内説明）：土台（コア）にインデックスファンドを置き、攻め（サテライト）に個別株やナスダック100等を組み合わせる手法。

4. 数字一覧（金額・率・上限・期限）※文字起こしにあるもののみ
・レベル1の定義：純資産160万円未満（1万ドル未満、1ドル160円換算）
・レベル2の定義：純資産160万円〜1600万円（1万〜10万ドル）
・レベル3の定義：純資産1600万円〜1億6000万円（10万〜100万ドル）
・0.01%ルール（純資産に対する悩まず使える金額の目安）：純資産100万円で100円、1000万円で1000円、1億円で1万円
・借金金利の例：年15%（動画内の言及）
・投資リターンの例：年5%（動画内の試算例）
・シミュレーション例（レベル3の入り口1600万円から毎月10万円積み立て、年5%運用）：10年後4160万円、20年後8350万円、25年後1億1370万円

5. メリット / デメリット / リスク
・メリット：自分の資産レベルに応じた無理のない戦略をとることで、精神的な不安を減らしながら効率的に資産を増やせる。
・デメリット / リスク：レベル1で高金利の借金を抱えたまま投資をすることや、レベル2以降で生活水準を上げすぎて入金力が削られるリスク。また、資産が大きくなるにつれて相場の値動きによるメンタルへの負荷や損失額が大きくなるリスク。

6. 視聴者が取れるアクション（手順・時期）
・自身の資産レベル（レベル1〜3）を把握する。
・レベル1の場合：生活費の1〜3ヶ月分の現金を確保し、高金利の借金があれば先に返済する。固定費の見直しや人的資本（収入アップ）を優先する。
・レベル2の場合：低コストのインデックスファンド（オルカンやS&P500など）で自動積み立てを行い、入金力を高める。生活水準を急激に上げない。
・レベル3の場合：コア・サテライト運用を取り入れ、退場しないためのリスク管理を行う。
