1. 一言サマリー（誰向け・テーマ）
対象者：新NISAの平均投資額などの大きな数字を見て焦っている人、投資額が少ない人、これから始める人
テーマ：金融庁発表の2025年最新NISAレポートを基に、実際の日本人の投資実態や平均額の裏側を解説し、マイペースな長期投資の重要性を伝える内容

2. 対象者・前提条件（年齢、所得、世帯、雇用形態 等）
動画内での言及：
・年代別の口座保有率は30代で38%、40代で34%、50代で30%（ニッセイ基礎研究所のデータによる動画内説明）
・10人のうち6〜7人（40代・50代・60代の過半数）はNISA口座を保有していない前提

3. 制度・商品・施策名と要点
制度名：新NISA（つみたて投資枠、成長投資枠）
要点：
・政府目標を前倒しで上回る買い付けが進む一方で、口座保有率は全世代で4割未満であり、日本全国に行き渡っているわけではないと動画内では説明
・2025年中の買い付けが0円だった口座が約36.6%（1044万口座超）存在し、止まっている最大の理由は資金不足ではなく「やり方が分からない」といった最初の一歩のハードルであると指摘
・成長投資枠でも個別株より投資信託（インデックス投資が中心）が多く買われている傾向にあると説明

4. 数字一覧（金額・率・上限・期限）※文字起こしにあるもののみ。無い数字は捏造しない
・NISA累計買い付け額：約71万4000億円（政府目標：2027年末までに56兆円）
・NISA口座数：約2821万口座（目標：3400万口座）
・年代別口座保有率（動画内説明）：30代 38%、40代 34%、50代 30%
・2024年のNISA買い付け額：約17兆円、2025年：約18兆7500億円
・2025年中の買い付けが0円だった口座：約1044万6488口座（約36.6%）
・2025年中に1円でも買い付けをした口座数：約1811万口座
・2025年の1口座あたり平均年間投資額：約103万5000億円（月額換算約8万6000円）
・年間買付額が0円超60万円以下の講座（月5万円以下）：約1011万口座（買い付けをした講座の56%）
・年間300万〜360万円以下の満額に近い講座：約164万口座（約9%）
・つみたて投資枠で年間40万円以下（月3万3000円以下）の割合：約62%
・つみたて投資枠のみ利用の割合：約42%（約769万口座）
・インデックス投資の割合（区分できた投資信託内）：約94%（約5兆4700億円）

5. メリット / デメリット / リスク
メリット：
・少額（月1万円など）であっても、時間をかけて長く市場に残り続けることで資産形成が期待できる（動画内説明）
・つみたて投資枠などの地道なインデックス投資が多くの人を支えており、再現性が高い（動画内説明）
リスク・デメリット：
・平均投資額などの大きな数字を見て無理な金額を入れたり、相場下落時に焦って売却してマイナスで退場するリスクがある（動画内説明）
