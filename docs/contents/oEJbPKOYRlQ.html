1. 一言サマリー（誰向け・テーマ）
資産形成中で「いつまで投資を続ければいいのか」と悩む人向けに、老後の生活費不足分を逆算し、追加投資を減らして資産運用と現在の体験（人生の充実度）を両立させる「放置ライン（ゴール）」を解説するテーマ。

2. 対象者・前提条件
・毎月の積立投資を継続中で、ゴールが見えにくくなっている人
・資産額を増やすことだけでなく、現在の生活や体験への支出も重視したい人
・前提条件として動画内のシミュレーションでは年利5%の運用を仮定

3. 制度・商品・施策名と要点
・インデックスファンド等の運用資産を活用した老後取り崩し戦略
・書籍「DIE WITH ZERO」のタイムバケット（年齢ごとの体験計画）の考え方を組み合わせ、老後の生活費不足分を運用資産から取り崩す手法
・元本が大きくなると運用収益が生活費の一部を賄うようになるため、必要な入金額を減らして「放置」が可能な状態を作るとの説明

4. 数字一覧（金額・率・上限・期限）※文字起こしにあるもののみ
・理想の生活費の例: 月40万円（内訳例：生活費25万円、外食・趣味4万円、旅行8万円、家電・修繕3万円）または年120万円の旅行（月換算10万円）
・公的年金等収入の例: 月25万円
・投資資産からの月間不足額（取り崩し額）の例: 月10万円（年間120万円）、月15万円（年間180万円）、月20万円（年間240万円）
・取り崩し期間の前提: 65歳から95歳までの30年間
・シミュレーション上の元本と受け取り額の例:
  - 2000万円から月10万円受取（30年総額3600万円、30年後残高約472万円）
  - 3000万円から月15万円受取（30年総額5400万円、30年後残高約78万円）
  - 4000万円から月20万円受取（30年総額7200万円、30年後残高約944万円）
・簡易計算式: 毎月欲しい不足額の200倍が必要資産の目安（年間6%取り崩し計算に基づく）
・現金クッションの例: 2年分の取り崩し資金（月10万円受取なら240万円）
・追加投資なしの運用例: 1000万円を15年間運用した場合の成果（年利5%で約2079万円、年利7.5%で約2959万円、年利10%で約4107万円）
・0から目標額を作るための15年積立額（年利5%）の例:
  - 2000万円：月7万6000円
  - 3000万円：月11万3000円
  - 4000万円：月15万1000円
・1000万円保有者が15年後に目指す場合の積立額（年利5%）の例:
  - 3000万円：月約3万5000円
  - 4000万円：月約7万3000円

5. メリット / デメリット / リスク
・メリット: 必要なゴールが明確になることで、過度な節約をやめて現在の体験や旅行にお金を回せるようになる。資産の複利効果と取り崩しにより、元本以上の総額を受け取れる可能性がある。
・デメリット / リスク: 投資には絶対がなく、将来相場が長期低迷するリスク（AIバブル崩壊等の仮定シナリオ）がある。シミュレーション通りのリターンが得られない可能性がある。

6. 視聴者が取れるアクション（手順・時期）
1. 年金定期便などで受給見込み額を確認し、希望する生活費との差額（毎月の不足額）を算出する。
2. タイムバケットを作成し、10年単位で年齢ごとのやりたいことや生活費を書き出す。
3. 不足額から必要な資産額を計算し（月額×200など）、動画概要欄のシミュレーター等で確認する。
4. 数年分の現金クッションの確保、年1回の取り崩し額の調整、税金や信託報酬を考慮した余裕を持った計画づくりを行う。

7. 注意・免責（個別事情で変わる点、動画主張≠公式見解）
・動画内のシミュレーションは年利5%で計算されたものであり、将来の運用成果を保証するものではない。
・投資判断は自身のリスク許容度の範囲内で行うこと。
・特定の投資手法や書籍の考え方は動画内の主張であり、公式な見解や確実な利益を約束するものではない。
