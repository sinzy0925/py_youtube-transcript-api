1. 一言サマリー（誰向け・テーマ）
50代・60代の投資家向け。特定口座の配当金生活における、後期高齢者医療制度等の社会保険料負担への影響と対策についての動画内説明。

2. 対象者・前提条件
後期高齢者医療制度の原則として75歳以上の加入者（動画内では5年以内を目安に開始されるとの説明）。

3. 制度・商品・施策名と要点
- 制度名: 後期高齢者医療制度（保険料計算・窓口負担割合）
- 要点: 従来は確定申告の有無で金融所得の反映が分かれていたが、今後は確定申告の有無に関わらず金融機関の情報を元に金融所得が保険料や窓口負担の判定に反映される仕組みへ変更されるとの説明。
- 対策の要点: 新NISA口座の活用、無分配型投資信託の定期売却による所得コントロール、現金の組み合わせ。

4. 数字一覧（金額・率・上限・期限）
- 厚生労働省モデル例（夫年金230万円、金融所得50万円、妻基礎年金83万円の夫婦）：
  - 確定申告なしの場合: 年間保険料11万8000円程度、窓口負担1割
  - 確定申告ありの場合: 年間保険料16万9000円、窓口負担2割
- シミュレーション例（運用資産2000万円から年間80万円取り崩し）：
  - 高配当株（利回り4%）：年間配当80万円全額が金融所得
  - 無分配型投資信託の定期売却（元本1000万円、含み益1000万円から80万円売却）：利益部分の40万円が金融所得
  - NISA口座での配当・売却：金融所得0円
- 期限・時期の目安: 対象変更は5年以内を目安に開始されるとの動画内説明。

5. メリット / デメリット / リスク
- メリット: 定期的な現金収入が得られる、売却の手間がない（高配当株）。NISAや無分配型投資信託を活用することで金融所得を抑え、保険料負担を軽減できる可能性。
- デメリット / リスク: 特定口座で配当金を受け取り続けると金融所得が増え、後期高齢者医療制度の保険料や窓口負担割合が引き上げられるリスク。焦って特定口座の株を全て売却すると、含み益に対して多額の税金がかかるリスク。

6. 視聴者が取れるアクション（手順・時期）
- 自身の特定口座の高配当資産額と、将来（75歳時点など）の年間配当予定額を確認する。
- 今後の新しい投資先として、新NISAや無分配型投資信託（インデックスファンド等）の活用を検討する。
- 65歳から74歳までの期間を調整期間とし、資産の取り崩し方法（配当、定期売却、現金の組み合わせ）を計画する。

7. 注意・免責
- 個別の税負担、保険料、住民税の適用などは個人の所得や自治体、年度により異なるため、動画の主張がそのまま公式見解とは限らない。
- 制度変更や税率等は個別の事情によって大きく変わるため注意が必要。
