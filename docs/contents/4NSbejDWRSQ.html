1. 一言サマリー（誰向け・テーマ）
FIRE（早期リタイア）を目指す人向け。オルカン（全世界株式）とSCHD（米国高配当株ETF）を組み合わせた「二刀流」の出口戦略（資産の取り崩しと配当受給）について、過去のデータを用いたシミュレーションを交えて解説するテーマ。

2. 対象者・前提条件
年齢・所得・世帯等の詳細な指定なし（動画内では1800万円の初期投資を想定）。雇用形態は問わないが、投資による資産運用・取り崩しをリタイア後の収入源とする前提。

3. 制度・商品・施策名と要点
- オルカン（全世界株式インデックスファンド）：世界経済の成長を取り込み、長期で資産全体を大きく増やす（成長エンジン）。
- SCHD（米国高配当株ETF）：財務健全性等の条件で絞り込んだ高配当株を集めたETF。保有株を売却せずに定期的な配当収入を得る（現金収入エンジン）。
- 二刀流FIRE戦略：オルカンから定率取り崩しを行い、SCHDから配当を受け取ることで、売却量を抑えつつ資産成長と現金の双方を狙う出口戦略。
- 現金クッション：暴落時にオルカン等の売却を避けるため、生活費の数年分を現金として別で保有する対策。

4. 数字一覧（金額・率・上限・期限）※文字起こしにあるもののみ
- 初期投資額：合計1,800万円（オルカン1,000万円、SCHD800万円）※2012年1月一括投資のシミュレーション
- オルカン取り崩し率：毎年1月時点の評価額の4%（定率）
- SCHDの分配利回り（2026年7月時点）：約3.4%（過去12ヶ月）
- 2026年8月時点の資産残高：約1億315万円（オルカン4,030万円、SCHD6,285万円）
- 累計受給額（オルカン取り崩し＋SCHD手取り配当）：累計2,421万円（オルカン1,213万円、SCHD1,209万円）
- 最大ドローダウン（2020年3月コロナショック時）：-23.9%
- SCHD銘柄数（2026年7月時点）：約100銘柄
- 現金クッションの目安：生活費3年分程度（例：年間生活費300万円なら約900万円前後）

5. メリット / デメリット / リスク
- メリット：インデックスによる資産成長と、高配当株からの定期的な現金収入を同時に得られる。相場下落時に配当が入ることで、含み損を抱えたまま株を売却する心理的負担を和らげる効果がある。
- デメリット / リスク：オルカンとSCHDは株式同士であり値動きの相関が高いため（月リターンの相関87.7%）、暴落時には同時に下落する（暴落を完全に防ぐ仕組みではない）。為替変動リスク（円高・円安による受取配当額の変動）や、企業の減配リスク、検証期間（2012年以降の好景気）が今後も続くとは限らないリスクがある。取り崩し額が時価連動のため生活費が変動する。
