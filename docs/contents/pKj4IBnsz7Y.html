1. 一言サマリー
誰向け・テーマ・動画の構成: 全世界株式インデックスファンド（オルカン）の保有者を対象に、2024年8月のMSCI定期入れ替えや直近の値動き、市場の変化を解説する定点観測企画（オルカン通信 #4）。
構成は、値動きの振り返り、地域別リターンの状況、上昇の牽引役（業種別分析）、新興国指数の変化、8月の定期入れ替えレビュー、そしてスペースXの組み入れについての6トピック。

2. 対象者・前提条件
全世界株式系のインデックスファンド（オルカンなど）に投資している投資家、特に積立投資継続中でオルカンの仕組みや内部の変化への理解を深めたい人。話者自身は2018年から全世界株式インデックスファンドに投資しており、金融資産の半分以上が同ファンド。

3. 制度・商品・施策名と要点
- 商品名: eMAXIS Slim 全世界株式（オール・カントリー）、MSCI ACWI（オルカンが連動を目指す指数）
- 8月定期入れ替え（MSCI ACWI）の要点:
  - 追加55銘柄、削除92銘柄（差し引き-37銘柄）。小型株を含むACWI IMIでは追加184銘柄、削除279銘柄（差し引き-95銘柄）。
  - 日本の追加は国際エレクトリック1銘柄、削除はJFEホールディングスとセーブホールディングスの2銘柄。
  - 台湾は半導体や基盤関連が6社追加され、セメント・銀行・海運・ゲーム・バイオなどが削除。
  - 中国は太陽光関連企業（Jソーラー、トリナソーラー、ポリシリコンメーカーなど）、自動運転、不動産、ソフトウェア企業が削除される一方、半導体関連が追加。
  - アメリカはソフトウェア系の削除が目立つ。先進国全体の完全時価総額トップ3追加はサンディスク（アメリカ、フラッシュメモリー）、カーペンターテクノロジー（アメリカ、航空宇宙向け特殊合金）、ATI（アメリカ、特殊素材）の3つの物づくりの会社。
- スペースXの組み入れの要点:
  - 6月12日の上場から17日後の6月29日にオルカンに組み入れられた。
  - 大型IPOには上場3営業日目の寄り付き前までに発表し10営業日目の引け後に採用する早期採用ルール（3ヶ月の待機期間免除）があり、特別扱いではなく規定通りの適用。
  - オルカン内の比率は当初0.08%。理由は発行済み株式のうち市場で売買できる不動株が約5%程度しかなかったため。
  - S&P 500は早期採用ルールを検討のうえ否決され現時点で未採用。ナスダック100は7月7日に採用され比率約1%、9月のリバランスで不動株更新により3.5%を超える可能性があるとの説明。

5. メリット / デメリット / リスク
- メリット: オルカンは分散効果によりどの期間で切り取っても致命傷を負うようなタイミングがなく、ずっと2位か3位をキープする。伸びた地域の比重が自動的に上がり、特定の国やセクターを自分で選定・予測する労力が不要。
- デメリット / リスク:
  - 業種別の上昇が半導体などに非常に偏っており、世界株式の上昇の76%が2つの業種グループで説明される状態にあるため、下落に対するクッションが薄くなっている。
  - MSCIレポートによれば株式リスクプレミアムがドットコムバブル期以来の低水準に縮んでおり、利益成長がつまづいた際に株価を支えるクッションが薄い状態にある。
  - 円高に触れた場合、円建てのリターンは素直に下がる。
  - 新興国という括りの中身がバラバラになっており、新興国全体を一括りにした投資判断は実態に合わなくなっている。

6. 視聴者が取れるアクション
- 積立投資を継続している人は、短期的なギザギザした値動きや円高をマイナスに捉えず、より多くの外国株を買える機会と捉えて淡々と積立を継続する。
- 変化する指数の内部構造（半導体への偏りや新興国内の相関低下など）を定点観測（オルカン通信などの視聴）を通じて理解し、下がった時の心の持ち用や握力を維持する。
