    誰向け・テーマ・動画の構成: 長期投資家を対象に、米国株・日本株・全世界株の週間相場振り返り、新NISAの人気投資信託の動き、および8月・9月の夏枯れ相場に向けた心構えを解説する動画。

    複数本紹介の本数と役割: 書籍『敗者のゲーム』（著者: チャールズ・エリス）からは市場に残り続ける重要性（長期リターンは数営業日に集中する点）を解説し、書籍『サイコロジー・オブ・マネー』（著者: モーガン・ハウスル）からは資産形成における長く生き残る重要性と複利の効果を解説している。

  2. 対象者・前提条件
    長期投資家、新NISAで積立投資を行っている投資家、夏枯れ相場や相場の乱高下に不安を感じている投資家。

  3. 制度・商品・施策名と要点
    ・S&P500 / ナスダック / ダウ / SOX / ファング+ / トピックス: 各種株価指数・商品。米国企業利益は強い一方、長期金利上昇や原油高・関税等のインフレ材料が株価の重しとなっている。
    ・新NISA人気の投資信託: 日経平均SOX、eMAXISの国内株式トピックス、ゴールド、新興国株式、ファング+などの週間・長期（2020年〜、6年前〜）の基準価格変動の動向。
    ・チャールズ・エリス著『敗者のゲーム』: 「20年間のリターンの2/3はわずか5営業日に集中していた」というデータを引き、華麗な一打よりも致命的なミス（高値での全額購入や安値での狼狽売り）をしないことが勝敗を分けると主張。
    ・モーガン・ハウスル著『サイコロジー・オブ・マネー』: 資産形成で最も重要なのは最高のリターンを狙うことではなく、長く生き残ることであると主張。借金投資や生活資金の投入、下落時の売却を避けることで複利を働かせる。

  5. メリット / デメリット / リスク
    ・メリット: 企業利益や景気・工場生産活動は強く、S&P500企業の86%が利益予想を上回るなど企業の実力自体は高い。長期で見れば市場に残り続けることで高いリターン（複利の効果）を得られる可能性がある。
    ・デメリット / リスク: 米国の長期金利高止まり、ブレント原油の一時100ドル突破によるコスト増、追加関税によるインフレ圧力、円安による輸入コスト増大が株価の重しとなっている。韓国市場など半導体への集中度が高い地域は影響を直撃して下落している。
    ・失敗談・罠・シナリオ: 火曜日の高値で焦って全額を買ったり、金曜日の安値で怖くなって全部売ったりするような「致命的なミス」を犯すリスク。また、生活資金を投資に回したり、下落時にパニックになって市場から退場したりするリスク。

  6. 視聴者が取れるアクション
    ・生活防衛資金をしっかりと確保する。
    ・近いうちに使うお金を株式に入れない。
    ・1つの企業やテーマに資金を集中させず、借金をして投資を行わない。
    ・値動きの大きな商品はサテライト枠に抑える。
    ・下落（最大17%程度の想定）しても積立を続けられる金額設定にしておく。
    ・相場の下落時に一気に売買せず、いつもの日にいつもの金額を積み立て続ける。
