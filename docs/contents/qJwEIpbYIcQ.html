1. 一言サマリー（誰向け・テーマ）
投資初心者向けに、2026年8月から新NISA等で資産形成を始める際の方針として、全世界株式（オルカン）を土台にした長期・積立投資の具体的な配分と心構えを解説するテーマ。

2. 対象者・前提条件
投資初心者、長期の資産形成を目指す人、投資にかける時間をあまり取りたくない人、または値動きを許容しつつ経済ニュースを楽しみたい人。

3. 制度・商品・施策名と要点
- 制度・口座: 新NISA口座
- 主力商品: 全世界株式インデックスファンド（オルカン、例: eMAXIS Slim 全世界株式（オール・カントリー）、楽天・プラス・オルカンなど）、S&P500
- サテライト枠の候補: NASDAQ100、SOX指数、FANG+、AI関連ファンド等
- 運用方針の要点: 低コストで世界へ分散できるオルカンを土台（コア）に置き、自動積み立てを行う。投資経験や好みに応じてオルカン100%、またはコア7割・サテライト3割（オルカン・S&P500を7割、NASDAQ100等を3割）とする方針。

4. 数字一覧（金額・率・上限・期限）
- 消費者物価指数（動画内説明）: 2026年6月前年同月比1.7%上昇、2025年平均2.6%上昇
- オルカン運用実績（動画内説明）: 2026年7月末までの1年間で29.48%のリターン、直近3年で87.55%上昇
- 資金流入額（動画内説明）: 直近7月のeMAXIS Slimオルカンの1ヶ月間の資金流入額は4465億円
- シミュレーション例（年利5%想定）:
  - 毎月3万円: 20年後1249万円（元本720万円）、30年後2511万円（元本1080万円）、40年後（元本不明表記だが累計額456万円の旨記載）
  - 毎月5万円: 20年後2083万円、30年後4185万円、40年後7610万円
- オルカンの構成・規模（動画内説明）: 2026年6月末時点で2461銘柄、世界中の投資可能な株式の時価総額の約85%をカバー。テクノロジーセクターが31%を占める
- 為替影響（動画内説明）: 設定来の基準価格上昇のうち為替要因の寄与は7438円（2万817年のうちの割合として説明）
- 世界経済成長率予測（IMF見通し・動画内説明）: 2026年に3%、2027年に3.4%
- オルカン指標（動画内説明）: 2026年6月末のPERは23.64倍、予想利益PERは17.78倍
- 過去の暴落実績（動画内説明）: リーマンショック時の最大下落率は58.38%

5. メリット / デメリット / リスク
- メリット: 銘柄選定の手間がかからず、世界の勝ち組企業の入れ替わりを自動で組み込める。複利効果を得ながら長期で資産形成ができる。
- デメリット / リスク: 直近のハイペースな上昇が今後も続くとは限らず、購入直後に20%下落する可能性もある。米国や情報技術セクターへの集中、円高への反転による為替リスク、過去のリーマンショック級の暴落リスクがある。

6. 視聴者が取れるアクション（手順・時期）
- ネット証券（楽天証券やSBI証券など）で新NISA口座を開設し、オルカン等の投資信託を選ぶ。
- 給与等からの資金を毎月自動で積み立てる設定にする。
- まとまった余裕資金がある場合は一括投資の選択肢も検討する。
- コア・サテライト戦略をとる場合は、オルカン等を7割、好みのテーマ型ファンド等を3割に配分する。
- 投資開始後は相場を見て判断を変えず、積立を継続し、確認は半年から年に1度程度にとどめる。
