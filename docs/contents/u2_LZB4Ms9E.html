1. 一言サマリー（誰向け・テーマ）
配当投資家向けに、米国の増配株ETF「SCHD」とナスダック100カバードコールETF「563A」を50%ずつ組み合わせる配当ポートフォリオの有効性を解説する動画。

2. 対象者・前提条件
投資金額1000万円（SCHDに500万円、563Aに500万円）を想定。
追加投資なし、インカムは国内課税（20.315%）の税引後で計算。

3. 制度・商品・施策名と要点
- SCHD（シュワブ米国配当株式ETF）: 財務の質や配当継続性を審査した米国大型配当株を対象とし、長期の増配を狙う土台。
- 563A（グローバルX NASDAQ100デイリー・カバード・コールETF）: ナスダック100をベースに、翌日満期のコールオプション（1DTS戦略）を活用して毎月分配を目指す高インカムの攻め用ファンド。
- 組み合わせの要点: 安定性と長期増配のSCHDと、毎月の高キャッシュフローを狙う563Aを半々で持つことで、守りと攻めを両立させる。

4. 数字一覧（金額・率・上限・期限）※動画内説明
- 投資合計額: 1000万円（SCHD 500万円 / 563A 500万円）
- SCHD分配利回りの前提: 3.25%
- 563A分配利回りの前提: 15%（動画内では15%で固定シミュレーション）
- 563A運用管理費用: 0.2775%（公式データ）
- 563A資産残高: 338億円（公式データ）
- 初年度の月額手取り配当（シミュレーション）: 合計約6万593円（SCHDから約1万790円、563Aから約4万9803円）
- 初年度の年間手取り配当・利回り: 72万円（利回り7.2%）
- 長期シミュレーションの増配率前提: SCHDは過去5年平均の7%、563Aはインフレ率同等の2%
- 10年後・20年後の月額手取り配当（シミュレーション）: 10年後約7万9357円、20年後約11万1578円

5. メリット / デメリット / リスク
- メリット: SCHDによる長期的な増配と、563Aによる毎月の高インカムを同時に得られる。グロース優位相場への対応やディフェンスのクッション効果がある。
- デメリット / リスク: 563Aは株価急上昇時に上値を追いきれない可能性がある。上場からの実績期間が短く、15%の利回りは確定ではない。両ファンドとも株価変動リスクがあり、暴落時はナスタック100と同等に下落するリスクがある。投資対象が100%米国株のため、カントリーリスクおよび為替（円高）リスクを伴う。
