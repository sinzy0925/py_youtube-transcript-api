1. 一言サマリー（誰向け・テーマ）
高配当株投資を続けたい初心者を対象に、株価の変動に惑わされず長期保有するためのメンタル強化法や考え方（ゴリラ握力）を解説した書籍の要約。

2. 対象者・前提条件（年齢、所得、世帯、雇用形態 等）
動画内では、40代を中心に30代から50代の世代や、子育てなどの大きな出費が一段落し、老いに向けた資産形成を本格的に開始する層に向けた内容として説明されている。

3. 制度・商品・施策名と要点
- 高配当株投資・増配株投資（配当が毎年成長する企業への投資）
- 3つのエンジン: 企業による増配、配当金からの再投資、自己資金による追加投資
- ゴリラ握力: 何があっても株を握り続ける心理面のテクニック
- KDDI株の活用法: ディフェンシブ銘柄を待機資金（緩衝材）の代わりに保有し、急落時に売却して値下がりした株を買い増す原資にする発想
- 紹介された厳選21銘柄の例（動画内説明）: INPEX、大和ハウス工業、積水ハウス、JT、ヒューリック、ENEOSホールディングス、ブリヂストン、デンソー、トヨタ自動車、伊藤忠商事、丸紅、三菱商事、三菱UFJフィナンシャル・グループ、三井住友フィナンシャルグループ、オリックス、三菱HCキャピタル、第一生命グループ、東京海上ホールディングス、NTT、KDDIなど。

4. 数字一覧（金額・率・上限・期限）※文字起こしにあるもののみ。無い数字は捏造しない
- 年間配当金: 120万円（仕事をやめるまでに目指す目安）
- 月10万円の配当
- プラマイ10%は誤差の範囲
- 三菱商事の米国天然ガス開発会社買収額: 約1.2兆円（動画内説明）
- 労働収入が途切れる前提の年齢例: 65歳（50歳の方なら残りの期間として15年を想定）

5. メリット / デメリット / リスク
- メリット: 株価の変動に一喜一憂せず、企業の利益や増配に注目して精神的に安定して長期保有しやすくなる。配当金が生活コスト（水道代・電気代など）の負担軽減に寄与する。
- デメリット / リスク: 業績悪化する銘柄を選んだ場合、含み損や減配のリスクがある。株価の急変動により心理的負担が生じる可能性がある。

6. 視聴者が取れるアクション（手順・時期）
- 書籍のAmazonサンプル目次等を確認し、内容や厳選銘柄のラインナップをチェックする（動画内説明）。

- 評価額の変動に動じないためのメンタルテクニック（含み損は筋肉痛、7割で見積もるなど）を意識して資産形成を行う（動画内説明）。
