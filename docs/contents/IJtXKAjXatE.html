対象: 長期的な資産形成を目指す個人投資家

5. メリット / デメリット / リスク
- メリット:
  - 初心者でも再現しやすく、売買判断の回数を減らせるため余計なコストや判断ミスを防げる。
  - 指数が成長企業を自動的に入れ替えるため、個別株選びの失敗リスクを抑えられる。
  - 長期で市場に留まることで、企業利益の成長と複利効果を最大限に活かせる。
- デメリット / リスク:
  - 短期的な暴落（戦争、インフレ、AIバブル崩壊懸念など）により、一時的に資産価値が大きく目減りするリスクがある。
  - タイミングを測って売買しようとすると、買い戻しに失敗して上昇の恩恵を逃すリスクが高まる。

- 資産をコア（約7割）とサテライト（約3割）に分割する。
- 暴落や不安なニュースに直面した際は、売却ボタンを押す前に以下の3点を確認する：

- 頻繁に相場を見ず、淡々と積立を継続する。
