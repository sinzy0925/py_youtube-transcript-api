1. 一言サマリー
成長株投資に関する4冊の書籍を通じ、インデックス投資を補完・超えるための個別株投資の考え方、銘柄選定基準、テーマ投資、及び割安株との組み合わせについて一気に学ぶ総集編。動画の構成は、杉村太蔵『骨太の株式投資術』、テンバガー投資家Xの書籍（タイトル等未言及）、フィリップ・フィッシャー『株式投資で普通ではない利益を得る』（原書名等未言及）、久保田正幸『2000億円超を運用した伝説のファンドマネージャーが明かす超成長株の見つけ方』の順で4冊を紹介する。

2. 対象者・前提条件
個別株入門者、インデックス投資に物足りなさを感じている投資家、老後資金だけでなく現役世代で大きな利益を狙いたい投資家、企業分析や成長株・割安株の選定基準を学びたい投資家。

3. 制度・商品・施策名と要点

杉村太蔵『骨太の株式投資術』（文藝春秋）
- 資産形成と投資の定義の違い：資産形成はオルカンやS&P500等で自分のお金を守り積み上げる行為（貯金に毛が生えたものと動画内では表現）。投資とはリスクを取って未来を信じ社会を良くする使命感でお金を投じる行為。
- 新NISAの捉え方：小泉政権時のトリクルダウン理論の反省を踏まえ、2024年の新NISAこそが大企業の利益成長の恩恵を個人が非課税で得る新しいトリクルダウンであるとする。
- 骨太の方針の活用：経済財政諮問会議で決定される国の経済の大きな方向性（骨太の方針や基本方針2025、賃上げ支援、地方創生2.0、AI・半導体、防災、宇宙海洋など）を読み解き、政府が後押しする分野に中長期で投資する重要性。
- 個別株の定量的・定性的分析：PER、ROE、フリーキャッシュフロー、配当利回りなどの基本財務指標（定量）と、ビジネスモデルや経営等の定性的側面の双方を重視する。10年で2倍を狙う王道の推し株と、10年で10倍を狙う国が推す分野の推し株を紹介。

テンバガー投資家Xの書籍
- IPOセカンダリー投資の手法：上場後のIPO銘柄に投資してテンバガー（10倍株）を狙う。抽選に当たる必要がなく、上場後1年以内（効率重視）または5年以内から選定する。
- テンバガーの条件と特徴：日本株の25%（日経マネー特集による過去データ等）がテンバガーを達成。情報通信業やサービス業、電気機器、小売業などに多く、7割が時価総額50億円未満の小型株から達成されている。未成熟で過小評価されている段階や、機関投資家の投資対象に達した際の買いのエンジンを狙う。
- テンバガーに近い3つのビジネスモデル：
  1. ストックビジネス（例: 株式会社アズまーむ、解約率の低さが重要）
  2. 他店舗展開型（例: 株式会社チャームケアコーポレーション、介護施設など地方から全国展開）
  3. 営業人員依存型（例: パートナー、採用力と戦力化の教育力が重要）
- 短期売買の併用（上級者向け）：長期保有銘柄の動きの癖や決算特徴を把握した上で、同じ銘柄で短期回転や信用買いを組み合わせる（空売りは絶対しない）。

フィリップ・フィッシャー『株式投資で普通ではない利益を得る』
- 成長株投資の原則：10%や20%ではなく、数年間で10倍近くになる株価の成長に興味を持つべき。「良い投資をすれば誰でも億万長者になれる」。バフェットの投資スタイルの15%を形成。
- 周辺情報利用法：株価指標や業績等の数字だけでなく、会社の関係者、顧客、競合企業の関係者、業界団体の幹部など身近な人々のコメントや情報（数字に現れない側面）を重視する。実行難易度は高いが、バイアスや傲慢さを防ぎ罠を避けるために重要。
- 15のポイントの要点：企業の効率的な研究開発投資（10年分の成果等）、平均以上の販売体制・セールス・物流の仕組み、将来の利益率の維持・向上に向けた努力、良好な労関係（個人の小さな不満への早期対応）、長期的な利益を見据えた行動（困難に陥った顧客への支援）。
- 戦時の投資姿勢：戦争の脅威や勃発による暴落時に恐れて売るのではなく、心理の逆手を取り、インフレ時の現金退避を避けて株を買うべきとする。

久保田正幸『2000億円超を運用した伝説のファンドマネージャーが明かす超成長株の見つけ方』（日本経済新聞出版）
- 負け癖を克服する5つの鉄則：良い損切りを学ぶ（含み損の銘柄は悪い銘柄の可能性が高く、20%以上含み損があれば一旦売る、利益確定より悪材料での売却を優先）、ポートフォリオの見直しは6ヶ月に1回程度で十分、銘柄選びはIRや決算書を自分で読んで決める、売買前に株価チャートを見る。
- 小型成長株の3つのステージ：
  1. 黎明期（利益がほぼないか赤字、PER50〜100倍超、将来の夢）
  2. 急成長期（売上・利益が年50〜100%伸びる、PER30〜50倍、最も旨味がある）
  3. 成熟期（増益率が年10%未満に鈍化、PER15〜20倍程度）
- 成長株を見極める4つの条件：市場の成長性、市場のシェア、参入障壁、マネタイズ力（NVIDIAの事例等で解説）。
- 4つの有望成長テーマ：AI関連（インフラ側と新しいサービス・コンテンツを生み出す活用側に分類）、エネルギー革命（地熱発電、核融合発電のハードルと期待）、バイオ、宇宙開発。
- 割安株投資の併用：超成長株だけでなく、インフレが追い風になる3大割安セクター（金融、資源関連、製造業）のピカピカだが割安に放置されている激安株に分散しバランスよく持つのも重要。

4. 数字一覧
- 杉村太蔵著の紹介パート：新NISA開始後のオルカンのリターンは2年ちょっとでプラス65%（動画内説明）。日経平均株価8万円になるという強気姿勢の言及（動画内説明）。
- テンバガー投資家Xの書籍紹介パート：
  - 著者の実績：3年9ヶ月で約700万円から約6700万円、さらに1年半で6億円以上に増加（動画内説明）。
  - 日本株のテンバガー実績：リーマンショック最安値から株価10倍を達成した日本株は2022年1月末時点で946銘柄（当時上場していた3769銘柄の約1/4）。平均期間8.2年（8割が5年以上）。上場後20年未満の新興銘柄が半数を占める。特に2007・2008・2010年上場銘柄は2社に1社が10倍達成。
  - 時価総額の傾向：7割が時価総額50億円未満から10倍を達成。100億円を超えると数が1/5程度に減少。
  - 著者の個別実績：株式会社アズまーむで17倍などを獲得。
- フィリップ・フィッシャー著の紹介パート：
  - 出版年：1958年。
  - バフェットの投資スタイルの構成比言及：バフェットは自分について「85%はグレアム、15%はフィッシャーからできている」と語る。
- 久保田正幸著の紹介パート：
  - 著者の運用実績：25年にわたり公的年金や投資信託など2000億円を超える資産を運用、年間100社近くを取材し東証33業種全てを網羅。
  - 小型成長株のステージごとの数値目安：黎明期はPER50倍以上〜100倍超、急成長期は増益率年50〜100%・PER30〜50倍、成熟期は増益率年10%程度未満・PER15〜20倍程度。含み損20%以上での損切り検討。

5. メリット / デメリット / リスク
- インデックス投資（オルカン・S&P500等）：
  - メリット：貯金に毛が生えたような手堅い資産形成ができ、老後資金等の準備に有効。初心者でも手間がかからない。
  - リスク・デメリット：指数に置いていかれる個人投資家も多く、投資としての面白みや爆発的な利益（テンバガー等）は狙えない。
- 個別株・成長株投資（IPOセカンダリー・成長テーマ等）：
  - メリット：短期間または中長期で数倍〜10倍以上の大きなリターン（テンバガー）を狙うことができ、現役世代で自由なお金が手に入る。政府の骨太の方針や成長テーマ（AI活用等）に沿った企業分析や、プロの選定基準（4つの条件やビジネスモデル）を学べる。
  - デメリット・リスク：15年間負け続けた著者のようにテーマ株や米国株などで失敗するリスクがある。企業の成長ストーリーが崩れるリスク、株価の乱高下、資金が長期間拘束されるリスク、周辺情報利用法の実行難易度の高さ。
- 割安株投資：
  - メリット：財務内容が優れていながら割安に放置されている銘柄を組み入れることで、成長株一辺倒の攻めからポートフォリオのバランスを保てる。インフレ局面で業績を伸ばしやすい。

6. 視聴者が取れるアクション
1. インデックス投資だけでなく、個別株投資や成長株・割安株投資の考え方、企業分析の基礎（PER、ROE、フリーキャッシュフロー、配当利回り、財務諸表や決算説明書の読み込み）を学ぶ。
2. 骨太の方針や基本方針（AI・半導体、デジタルガバメント構想、防災、宇宙海洋、地方創生など政府が後押しする分野）のトレンドを確認し、中長期の投資ヒントとする。
3. 成長株スクリーニングおよび選定：
   - 上場後1年以内（効率重視）または5年以内のIPO銘柄、時価総額50億円未満の小型株に着目する。
   - ビジネスモデル（ストックビジネス、他店舗展開型、営業人員依存型）や、4つのチェック条件（市場の成長性、シェア、参入障壁、マネタイズ力）に照らし合わせて分析する。
4. 規律ある運用と損切りの徹底：
   - ポートフォリオの見直しは6ヶ月に1回程度に留め、短期の値動きに過度に囚われないようにする。
   - 悪材料が出た銘柄や持っていて辛い銘柄（含み損20%以上など）は良い損切りとして売却し、良い銘柄を残す。
   - 誰かの推奨銘柄をそのまま買わず、自分で事業内容やIRを確認して判断する。
